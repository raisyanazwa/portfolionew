Project 01 / 2026

Access Internship

projects, docs, and partners — one dashboard.

The story

Built during my PKL at CV Access Media, this platform gathers internship projects, documentation, and partner companies into one place — so mentors and interns always work from the same up-to-date information.

HTML CSS Tailwind JavaScript Node.js Worker SQLite API

Highlights

  • ✳Authentication with a role-aware dashboard.
  • ✳Project & documentation management with image uploads.
  • ✳Company directory with logo uploads and search.
  • ✳Soft delete and restore flow for archived records.
  • ✳Responsive layout for desktop and mobile.

APM

report, track, and follow up.

The story

APM (Aplikasi Pengaduan Masyarakat) is a community complaint application: residents submit reports, officers sort them by category, and the dashboard tracks every status until it is resolved.

PHP Laravel CSS MySQL JavaScript

Highlights

  • ✳Complaint submission form for residents.
  • ✳Category-based report management.
  • ✳Admin dashboard with complaint statistics.
  • ✳Response and status tracking per report.
